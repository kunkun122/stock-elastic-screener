# 股价高弹性筛选工作台

基于「四类核心指标」的 A 股高弹性标的筛选工具：β 系数 / 波动幅度 / 量能活跃 / 区间形态。

**在线使用**：https://kunkun122.github.io/stock-elastic-screener/

- 覆盖沪深300 + 中证500 + 中证1000 共 1799 只标的
- 参数自由调整，浏览器本地筛选，秒级响应
- 支持自选股导入（粘贴代码 / CSV 上传）
- 指标明细 + 雷达图 + Excel 导出

## 指标口径

| 指标 | 计算 |
|---|---|
| β 系数 | 近 120 日对基准回归 |
| 年化波动率 | 日对数收益 σ × √252 |
| 振幅 / 换手率 | 近 20 日均值 |
| 布林带宽分位 | 当前带宽在近 120 日中的分位 |

数据来源：新浪财经日线 + 中证指数成分。数据为每日更新快照，页面顶部显示生成时间。

> 仅供研究参考，不构成投资建议。
